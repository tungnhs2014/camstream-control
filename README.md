# CamStream Control

CamStream Control is a Linux camera streaming and control platform built to
demonstrate Buildroot platform integration, USB UVC/V4L2 camera support,
GStreamer multimedia pipelines, and modern C++ service architecture.

## Reference target

- Board: BeagleBone Black
- Camera: USB UVC camera
- Build system: Buildroot
- Multimedia: V4L2 and GStreamer
- Service: Modern C++ with Unix Domain Socket IPC

## Current status

Project initialization and engineering planning.

No platform, camera, or application functionality has been implemented yet.
